## 2. Безопасность: критичные находки закрыты

| Проблема (аудит 25.11) | Решение |
|---|---|
| Нет верификации скачиваемых бинарников | SHA256-дайджест GitHub **обязателен** для tg-ws-proxy и CDPI-наборов (несовпадение = отмена установки + удаление файла); для Zapret — иммутабельный URL по полному коммиту + фиксация хэша архива |
| TOCTOU версии Zapret (`master` ветка) | Скачивание `codeload/.../zip/<full-sha>`, версия = short sha коммита |
| Path traversal в `store_remove` | `valid_store_id` (regex + проверка canonical-пути внутри kits/), тесты на traversal |
| `auto_apply` принимал произвольный template (winws2 умеет `--lua-init=@…`) | `template_allowed`: только template из каталога/репозитория/истории |
| `csp: null` при elevated-приложении и удалённом markdown | Строгий CSP: `default-src 'self' … object-src 'none' frame-ancestors 'none'`; `open_url` — allowlist схем (https, tg) |
| `atomic_write` не атомарен (remove+rename) | `MoveFileExW(REPLACE_EXISTING | WRITE_THROUGH)` |
| Битый settings.json молча сбрасывался | Бэкап `settings.corrupt-<дата>.json` + запись в app.log |
| Порт без верхнего/нижнего клампа | `clamp(1024, 65535)` |
| `tgws_restart` без проверки порта и флага | Переиспользует `start_proxy_impl` |
| Подмена бинарников после установки | `components::verify_installed` — сверка SHA256 exe; вызывается «Доктором» |
| Дублирование HTTP-клиента | Общий модуль `http.rs` (client/get_json/get_text/download, HTTPS-only, лимит 1 ГБ) |
| Zip-атаки | zip-slip гвард (тест), лимит распаковки 2 ГБ, лимит размера скачивания |

## 5. Остатки (осознанно не сделано)

1. **Служба SYSTEM (`hubd`)** — меняет модель привилегий и процессов; дизайн в
   `docs/ARCHITECTURE-PROPOSAL.md`. Без теста на реальной машине с сетью — недопустим.
2. **Per-app split** — требует форка winws2 (подход mqclass) или WinDivert-фильтров
   по процессам; частично закрыт режимами «по списку/весь трафик».
3. **Codegen TS-типов из Rust** (`specta`/`ts-rs`) — `types.ts` по-прежнему ручное
   зеркало DTO.
4. **DNS/DoH-переключатель** — в roadmap (DESKTOP.md §8).
5. **Подпись кода** (OV-сертификат) — платная история; README пока объясняет детекты антивирусов.
